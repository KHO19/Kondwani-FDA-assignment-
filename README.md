# Kondwani-FDA-assignment-
Overview
This project analyses the Wholesale Customers dataset to understand customer purchasing behaviour and support data-driven decision-making.
Dataset
The dataset contains 440 customers with annual spending across six product categories:
Fresh
Milk
Grocery
Frozen
Detergents_Paper
Delicassen
It also includes customer attributes such as Channel and Region.
Objectives
Explore and describe customer spending patterns
Segment customers based on purchasing behaviour
Build a predictive model to classify customers into segments
Methodology
The project follows the CRISP-DM methodology, including data exploration, preparation, clustering for segmentation, and supervised classification for prediction.
Tools
Python
Pandas, NumPy
Matplotlib
Scikit-learn
Outcome

The analysis identifies distinct customer segments and enables prediction of customer group membership to support targeted marketing and sales strategies
